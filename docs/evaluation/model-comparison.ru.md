## Интерпретация

В этом прогоне runtime gate поймал все известные контрольные значения Qwen, но четыре payload Gemma прошли реализованные проверки с ожидаемым чувствительным значением. Benchmark остановил эти четыре случая через fixture-oracle. Этот дополнительный oracle сравнивает результат с разметкой тестового набора и недоступен для обычного документа.

Поэтому `проходы fixture-oracle` — метрика оценки, а не число документов, разрешённых для реального облака. Ноль контрольных значений в этих проходах означает только то, что размеченный набор не выпустил известные остатки.

Qwen четыре раза вернул значения, которых не было во входе как точных подстрок. Эти случаи заблокированы до псевдонимизации. Ошибок JSON/schema в этом запуске не было. У Gemma выше recall и ниже медиана времени, но четыре размеченные утечки прошли runtime gate. Ни одна модель пока не подходит для автоматической обработки документов высокого риска.

Сборка Qwen помещала JSON, ограниченный schema, в `reasoning_content`, оставляя `content` пустым. Compatibility-path разбирает тот же JSON и применяет enum- и exact-substring-проверки.

Машиночитаемые результаты по каждому кейсу: [`live-combined.json`](live-combined.json). Команда повтора:

```bash
pii-airlock benchmark --models qwen,gemma --output docs/evaluation/live-combined.json
```

Повторные запуски могут различаться даже при temperature `0`; сборка модели и железо также влияют на результат.
